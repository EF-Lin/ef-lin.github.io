__main__

EFLin included in Python
 2024-10-31  315 words  One minute 
Contents
  • References

__main__.py是 python 中的一個特殊檔案，它是在利用python指令執行一個壓縮檔或資料夾時首先被運行的檔案。例如以下專案：

1
2
3
4

example |__main__.py
		| a.py
        | b.py
        | c.py

在 cmd 執行python example後，會自動執行python __main__.py。1

另外，在這段常見的程式碼中：

1
2
3

if __name__ == "__main__":
    print(__name__)
    # >>>__main__

檔案的__name__之所以會是__main__，就是因為 python 第一個執行的會是__main__這隻程式，因此在執行單一.py檔時，名稱才會被電腦分配為__main__。同時，由於 python 在 import 檔案時會先執行一遍該檔案，這麼做也是為了避免在 import 時意外執行某些不該執行的程式。2
